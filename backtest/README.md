# 기관 3일 연속 순매수 전략 백테스트

**가설:** 기관이 3일 연속 순매수한 종목을 다음 날 사서 5거래일 보유하면 시장보다 나은가?

---

## 실행 방법

```bash
cd backtest
pip install -r requirements.txt
python backtest.py
```

최초 실행은 전 종목(약 2,000개) 데이터를 KRX에서 내려받으므로 **2~4시간** 걸립니다.
`cache/` 폴더에 저장되므로 두 번째 실행부터는 몇 분이면 끝납니다.

먼저 빠르게 확인하려면:

```bash
python backtest.py --max-tickers 200      # 200종목 샘플, 약 20분
```

---

## 매매 규칙 (코드에 그대로 구현됨)

| 항목 | 내용 |
|------|------|
| 시그널 | D-2, D-1, D일 모두 기관합계 순매수 > 0 |
| 매수 | D+1일 **시가** |
| 매도 | D+6일 **시가** (5거래일 보유) |
| 대상 | KOSPI + KOSDAQ 보통주 (우선주·스팩 제외) |
| 기간 | 최근 3년 |
| 비용 | 왕복 33bp (수수료 0.015%×2 + 거래세 0.15% + 슬리피지 15bp) |

미래 정보를 쓰지 않습니다. 시그널 확정은 D일 장 마감 후, 체결은 D+1일 시초가입니다.

---

## 옵션

```bash
python backtest.py --streak 5 --hold 10          # 5일 연속 순매수 / 10일 보유
python backtest.py --min-inst-amount 1000000000  # 기관 순매수 합계 10억 이상만
python backtest.py --min-turnover 5000000000     # 거래대금 50억 이상 종목만
python backtest.py --cost-bps 50                 # 비용 가정 상향
python backtest.py --market KOSPI                # 코스피만
```

## 결과물

- `result_summary.txt` — 승률, 평균수익률, 연도별/시장별/순매수금액 분위별 성과
- `result_trades.csv` — 전체 거래 내역 (종목, 진입일, 청산일, 수익률)

### 반드시 같이 볼 숫자

리포트의 **초과 수익률(엣지)** 이 핵심입니다.

> 같은 기간 같은 종목을 **아무 날에나** 사서 5일 들고 있었을 때의 평균 수익률과 비교한 차이

한국 시장은 3년간 전반적으로 상승했기 때문에, 전략 승률이 55%라도 아무 날이나 산 승률이 54%면 **전략의 가치는 1%p**입니다. 절대 승률에 속지 마십시오.

## 검증

엔진 로직은 단위 테스트로 검증되어 있습니다. 네트워크 없이 바로 실행됩니다.

```bash
python test_engine.py
```

진입/청산 시점, 연속 조건, 거래비용 반영, 미래참조 없음, 필터 동작, 통계 집계,
그리고 **랜덤 데이터에서는 엣지가 0으로 나오는지**(과최적화 방지)까지 확인합니다.

## 한계 — 결과 해석 시 감안할 것

1. **생존 편향**: 현재 상장 종목만 대상입니다. 3년 사이 상장폐지된 종목이 빠져 있어 실제보다 수익률이 좋게 나옵니다.
2. **시초가 체결 가정**: 실제로는 시가에 원하는 수량을 다 못 삽니다. 거래대금 필터(`--min-turnover`)를 걸어야 현실적입니다.
3. **자금 무한 가정**: 하루에 시그널이 200개 나와도 전부 매수한 것으로 계산합니다. 실제 운용은 종목 선별이 필요합니다.
4. **기관합계 기준**: 연기금·투신·사모 등 세부 주체를 구분하지 않습니다. 세부 주체별 분석이 필요하면 말씀 주십시오.
