# 기관 / 기관+외국인 3일 연속 순매수 전략 백테스트

**가설:** 기관(또는 기관+외국인이 동시에) 3일 연속 순매수한 종목을 다음 날 사서
5거래일 보유하면 시장보다 나은가?

기본 실행하면 **두 조건을 같이 돌려서 비교표**를 출력합니다.

---

## 데이터 소스 — 토스증권 Open API (기본)

2026년 현재 KRX는 로그인 없는 조회를 막고 있어(`403`), pykrx만으로는
투자자별 순매수와 종목 목록이 **빈 값**으로 옵니다. 그래서 기본 데이터 소스를 토스로 바꿨습니다.

| 데이터 | 출처 |
|------|------|
| 종목 목록 (보통주, 우선주·ETF·리츠 제외) | 토스 Open API |
| 기관·외국인 순매수 | 토스 Open API |
| 시세 (시가·종가·거래량) | pykrx (로그인 불필요) |

### 1. 토스 Open API 키 발급

토스증권 Open API를 신청해 **client_id** 와 **client_secret** 을 발급받으십시오.

### 2. 허용 IP 등록 (필수)

토스는 앱에 등록된 IP에서 온 요청만 받습니다. 등록하지 않으면
`403 IP address not allowed` 가 납니다. 현재 PC의 공인 IP는 아래로 확인하십시오.

```bash
curl https://api.ipify.org
```

공유기를 재시작하면 IP가 바뀔 수 있습니다. 같은 오류가 다시 나면 IP부터 확인하십시오.

### 3. `.env` 작성

`backtest/.env` 파일을 만들고 **정확히 이 형식**으로 두 줄을 넣으십시오.
`=` 앞뒤에 공백을 넣지 마십시오. `Client id : 값` 같은 형식은 읽지 못합니다.

```
TOSS_CLIENT_ID=발급받은_ID
TOSS_CLIENT_SECRET=발급받은_시크릿
```

메모장으로 저장할 때는 파일 형식을 "모든 파일"로 골라야 `.env.txt` 가 되지 않습니다.

### 4. 확인

```bash
python backtest.py --check-toss
```

토큰 발급, 종목 목록, 삼성전자 3년치 매매동향 수신까지 한 번에 점검합니다.

### 토스 데이터의 차이 — 결과 해석 시 감안

- **순매수는 주식 수로만 제공됩니다.** 금액은 `순매수 주식 수 × 당일 종가`로 추정합니다.
  시그널(순매수 > 0)은 부호만 보므로 영향이 없고, 금액 필터·금액 구간 분석만 근사치입니다.
- **외국인은 등록외국인 기준**입니다. KRX의 등록+미등록 합계와 약간 다릅니다.
- 시세에는 거래대금이 없어 `종가 × 거래량`으로 추정합니다 (`--min-turnover` 에 사용).

### 보안 — 반드시 지키실 것

- 키는 **`.env` 파일에만** 넣으십시오. 코드나 채팅에 적지 마십시오.
  채팅·메신저에 키를 붙여넣었다면 즉시 폐기하고 재발급하십시오.
- `.env` 와 `*.env` 는 `.gitignore` 에 등록되어 GitHub 에 올라가지 않습니다.
- `.env.example` 에는 실제 값을 적지 마십시오. 이 파일은 GitHub 에 올라갑니다.

### (대안) KRX 계정으로 쓰기

KRX 계정이 있다면 `--source krx` 로 기존 방식을 쓸 수 있습니다. 순매수가 정확한 금액으로 나옵니다.
`requirements.txt` 에서 `pykrx==1.0.51` 을 지우고 `pykrx==1.2.8` 주석을 푼 뒤 재설치하고,
`.env` 에 `KRX_ID=` / `KRX_PW=` 를 넣은 다음 `python backtest.py --check-krx` 로 확인하십시오.

## 실행 방법

Python 3.12 이상을 권장합니다. 가상환경을 쓰면 시스템 Python을 건드리지 않습니다.

```bash
cd backtest
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python backtest.py
```

최초 실행은 전 종목(약 2,500개) 데이터를 내려받으므로 **약 50분** 걸립니다.
`cache/` 폴더에 저장되므로 두 번째 실행부터는 몇 분이면 끝납니다.

먼저 빠르게 확인하려면:

```bash
python backtest.py --max-tickers 200      # 200종목 샘플, 약 5분
```

샘플은 종목코드 순 앞쪽 200개라 **전부 KOSPI 구종목**입니다. 결과가 전체 시장을 대표하지 않으니
형식 확인 용도로만 쓰고, 판단은 전 종목 결과로 하십시오.

## 매매 규칙 (코드에 그대로 구현됨)

| 항목 | 내용 |
|------|------|
| 시그널 (기관 단독) | D-2, D-1, D일 모두 **기관합계** 순매수 > 0 |
| 시그널 (기관+외국인) | D-2, D-1, D일 **각각** 기관합계 > 0 **그리고** 외국인합계 > 0 |
| 매수 | D+1일 **시가** |
| 매도 | D+6일 **시가** (5거래일 보유) |
| 대상 | KOSPI + KOSDAQ 보통주 (우선주·스팩 제외) |
| 기간 | 최근 3년 |
| 비용 | 왕복 33bp (수수료 0.015%×2 + 거래세 0.15% + 슬리피지 15bp) |

미래 정보를 쓰지 않습니다. 시그널 확정은 D일 장 마감 후, 체결은 D+1일 시초가입니다.

## 옵션

```bash
python backtest.py                               # 기관 단독 + 기관+외국인 동시, 둘 다 비교(기본)
python backtest.py --mode inst                   # 기관 단독만
python backtest.py --mode inst+frgn              # 기관+외국인 동시만
python backtest.py --streak 5 --hold 10          # 5일 연속 순매수 / 10일 보유
python backtest.py --min-inst-amount 1000000000  # 기관 순매수 합계 10억 이상만
python backtest.py --min-frgn-amount 1000000000  # 외국인 순매수 합계 10억 이상만
python backtest.py --min-turnover 5000000000     # 거래대금 50억 이상 종목만
python backtest.py --cost-bps 50                 # 비용 가정 상향
python backtest.py --market KOSPI                # 코스피만
python backtest.py --source krx                  # KRX 계정으로 데이터 받기
```

- `result_summary.txt` — 조건별 상세 리포트 + **조건 비교표**
- `result_inst_trades.csv` — 기관 단독 조건 거래 내역

### 반드시 같이 볼 숫자

리포트의 **초과 수익률(엣지)** 이 핵심입니다.

> 같은 기간 같은 종목을 **아무 날에나** 사서 5일 들고 있었을 때의 평균 수익률과 비교한 차이

한국 시장은 3년간 전반적으로 상승했기 때문에, 전략 승률이 55%라도 아무 날이나 산 승률이 54%면 **전략의 가치는 1%p**입니다. 절대 승률에 속지 마십시오.

## 검증

엔진 로직은 단위 테스트로 검증되어 있습니다. 네트워크 없이 바로 실행됩니다.

```bash
python test_engine.py
```

14개 테스트가 다음을 확인합니다 — 진입/청산 시점, 연속 조건, 거래비용 반영,
미래참조 없음, 금액 필터 동작, 통계 집계, 그리고 외국인 조건 관련 5개:

- 외국인이 순매도면 동시 조건에서 배제되는가
- 기관·외국인 순매수일이 **같은 날**로 겹쳐야 시그널이 나는가
- 외국인 조건 시그널이 항상 기관 단독 시그널의 **부분집합**인가
- 외국인 순매수 금액 필터가 동작하는가

토스 API 응답 파싱도 검증하고, 마지막으로 **랜덤 데이터에서 엣지가 0으로 나오는지**(과최적화 방지)까지 확인합니다.

## 한계 — 결과 해석 시 감안할 것

1. **생존 편향**: 현재 상장 종목만 대상입니다. 3년 사이 상장폐지된 종목이 빠져 있어 실제보다 수익률이 좋게 나옵니다.
2. **시초가 체결 가정**: 실제로는 시가에 원하는 수량을 다 못 삽니다. 거래대금 필터(`--min-turnover`)를 걸어야 현실적입니다.
3. **자금 무한 가정**: 하루에 시그널이 200개 나와도 전부 매수한 것으로 계산합니다. 실제 운용은 종목 선별이 필요합니다.
4. **합계 기준**: 기관은 연기금·투신·사모 등을 구분하지 않고 합계로 봅니다. 외국인은 토스 기준 등록외국인,
   KRX 기준 등록+미등록 합계입니다.
   세부 주체별 분석이 필요하면 말씀 주십시오.
5. **초과수익은 같은 날·같은 시장 기준선과 비교해서 확인하십시오**: 시그널이 KOSPI에 몰리면
   KOSPI가 KOSDAQ보다 좋았던 기간에 리포트의 초과수익이 부풀려집니다. 5일 보유 거래는 서로 겹치므로
   거래 건수만큼 통계적 신뢰도가 높은 것도 아닙니다.
6. **외국인 조건은 거래수를 크게 줄입니다**: 표본이 100건 미만이면 승률 숫자는 우연입니다.
   조건을 걸었는데 거래수가 급감했다면 `--streak 2`로 완화하거나 기간을 늘려서 다시 보십시오.
