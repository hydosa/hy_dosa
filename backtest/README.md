# 기관 / 기관+외국인 3일 연속 순매수 전략 백테스트

**가설:** 기관(또는 기관+외국인이 동시에) 3일 연속 순매수한 종목을 다음 날 사서
5거래일 보유하면 시장보다 나은가?

기본 실행하면 **두 조건을 같이 돌려서 비교표**를 출력합니다.

---

## 실행 방법

```bash
cd backtest
pip install -r requirements.txt
python backtest.py
```

최초 실행은 전 종목(약 2,000개) 데이터를 KRX에서 내려받으므로 **2~4시간** 걸립니다.
`cache/` 폴더에 저장되므로 두 번째 실행부터는 몇 분이면 끝납니다.

먼저 빠르게 확인하려면:

```bash
python backtest.py --max-tickers 200      # 200종목 샘플, 약 20분
```

---

## 매매 규칙 (코드에 그대로 구현됨)

| 항목 | 내용 |
|------|------|
| 시그널 (기관 단독) | D-2, D-1, D일 모두 **기관합계** 순매수 > 0 |
| 시그널 (기관+외국인) | D-2, D-1, D일 **각각** 기관합계 > 0 **그리고** 외국인합계 > 0 |
| 매수 | D+1일 **시가** |
| 매도 | D+6일 **시가** (5거래일 보유) |
| 대상 | KOSPI + KOSDAQ 보통주 (우선주·스팩 제외) |
| 기간 | 최근 3년 |
| 비용 | 왕복 33bp (수수료 0.015%×2 + 거래세 0.15% + 슬리피지 15bp) |

미래 정보를 쓰지 않습니다. 시그널 확정은 D일 장 마감 후, 체결은 D+1일 시초가입니다.

---

## 옵션

```bash
python backtest.py                               # 기관 단독 + 기관+외국인 동시, 둘 다 비교(기본)
python backtest.py --mode inst                   # 기관 단독만
python backtest.py --mode inst+frgn              # 기관+외국인 동시만
python backtest.py --streak 5 --hold 10          # 5일 연속 순매수 / 10일 보유
python backtest.py --min-inst-amount 1000000000  # 기관 순매수 합계 10억 이상만
python backtest.py --min-frgn-amount 1000000000  # 외국인 순매수 합계 10억 이상만
python backtest.py --min-turnover 5000000000     # 거래대금 50억 이상 종목만
python backtest.py --cost-bps 50                 # 비용 가정 상향
python backtest.py --market KOSPI                # 코스피만
```

## 결과물

- `result_summary.txt` — 조건별 상세 리포트 + **조건 비교표**
- `result_inst_trades.csv` — 기관 단독 조건 거래 내역
- `result_inst_frgn_trades.csv` — 기관+외국인 동시 조건 거래 내역

거래 내역에는 종목, 진입일, 청산일, 기관 순매수 합계(`inst_sum`),
외국인 순매수 합계(`frgn_sum`), 수익률이 들어 있습니다.

### 반드시 같이 볼 숫자

리포트의 **초과 수익률(엣지)** 이 핵심입니다.

> 같은 기간 같은 종목을 **아무 날에나** 사서 5일 들고 있었을 때의 평균 수익률과 비교한 차이

한국 시장은 3년간 전반적으로 상승했기 때문에, 전략 승률이 55%라도 아무 날이나 산 승률이 54%면 **전략의 가치는 1%p**입니다. 절대 승률에 속지 마십시오.

## 검증

엔진 로직은 단위 테스트로 검증되어 있습니다. 네트워크 없이 바로 실행됩니다.

```bash
python test_engine.py
```

13개 테스트가 다음을 확인합니다 — 진입/청산 시점, 연속 조건, 거래비용 반영,
미래참조 없음, 금액 필터 동작, 통계 집계, 그리고 외국인 조건 관련 5개:

- 외국인이 순매도면 동시 조건에서 배제되는가
- 기관·외국인 순매수일이 **같은 날**로 겹쳐야 시그널이 나는가
- 외국인 조건 시그널이 항상 기관 단독 시그널의 **부분집합**인가
- 외국인 순매수 금액 필터가 동작하는가

마지막으로 **랜덤 데이터에서 엣지가 0으로 나오는지**(과최적화 방지)까지 확인합니다.

## 한계 — 결과 해석 시 감안할 것

1. **생존 편향**: 현재 상장 종목만 대상입니다. 3년 사이 상장폐지된 종목이 빠져 있어 실제보다 수익률이 좋게 나옵니다.
2. **시초가 체결 가정**: 실제로는 시가에 원하는 수량을 다 못 삽니다. 거래대금 필터(`--min-turnover`)를 걸어야 현실적입니다.
3. **자금 무한 가정**: 하루에 시그널이 200개 나와도 전부 매수한 것으로 계산합니다. 실제 운용은 종목 선별이 필요합니다.
4. **합계 기준**: 기관은 연기금·투신·사모 등, 외국인은 등록/미등록을 구분하지 않고 합계로 봅니다.
   세부 주체별 분석이 필요하면 말씀 주십시오.
5. **외국인 조건은 거래수를 크게 줄입니다**: 표본이 100건 미만이면 승률 숫자는 우연입니다.
   조건을 걸었는데 거래수가 급감했다면 `--streak 2`로 완화하거나 기간을 늘려서 다시 보십시오.
