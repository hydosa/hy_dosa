결과 해석 시 반드시 감안할 것

  1. 생존 편향 — 현재 상장 종목만 대상입니다. 기간 중 상장폐지된 종목이 빠져 있어 실제보다 결과가 좋게 나옵니다.
  2. 시가 전량 체결 가정 — 시그널이 하루 200개 나와도 전부 샀다고 계산합니다. --min-turnover 로 거래대금 필터를 걸어야 현실에 가깝습니다.
  3. 표본 수 — 거래수 100건 미만이면 승률은 우연입니다. 숫자를 믿지 마십시오.
  4. 절대 승률에 속지 말 것 — 장이 오른 구간에서는 아무거나 사도 승률이 나옵니다. 기준선과의 차이만 보십시오.
